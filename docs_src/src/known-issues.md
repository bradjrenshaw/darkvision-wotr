# Known Issues

- **Alpha**: not everything in the game is accessible yet, and some screens are only partial.
- The game switches Steam achievements off whenever a mod is loaded. Darkvision turns them back
  on (the **Achievements stay enabled with mods active** Enhancement). If you played with an earlier
  version before this existed, **Claim achievements already earned** in the same settings awards the
  story achievements you missed.
- **Console / controller mode is not supported** — PC keyboard only.

**Please report bugs** on the [issue tracker](https://github.com/bradjrenshaw/darkvision-wotr/issues).
The more detail the better — where you were, what you pressed, and what you heard versus what you
expected.
