* First public alpha of Wrath Access: screen-reader accessibility for Pathfinder: Wrath of the Righteous.
* New installer: WrathAccessInstaller.exe is now built on the Loadstone mod manager. It finds your Steam install, installs, updates and uninstalls the mod, can launch the game, and keeps itself up to date. Pick the newest release, or the dev channel for the latest build from the main branch.
* See the documentation (in game: Help, Read documentation) for installation, controls and a walkthrough, and the known issues page for what is still missing.
* Settings start fresh in this version: settings from earlier builds are not carried over (your old file is kept as settings.old.json next to the new one), and the setup wizard runs again.
